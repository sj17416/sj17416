이번 달, 어떤 글을 쓸까요?

선택 월의 자료와 조회 시점의 최근 월간 자료를 구분해 보여줍니다.

검색량은 선택 월 CSV 값을 우선 사용하고 없으면 최근 API 값을 사용합니다. CTR 필터는 광고 노출 100회 이상인 내 CSV 데이터만 적용하며, 미측정 항목은 제외합니다.

네이버 검색광고·데이터랩 연결은 연결 설정에서 합니다. 키가 없으면 측정값 없이 주제 후보만 표시됩니다.

네이버 검색광고 CTR과 내 블로그 애드센스 CTR은 서로 다릅니다. 다른 블로그의 광고 클릭률은 공개 검색으로 확인할 수 없습니다.

실제 측정값이 없는 항목은 ‘미측정’으로 표시합니다.

새 작성은 현재 글을 교체합니다. 이전 글 버튼으로 이번 실행 중의 기록을 되돌릴 수 있습니다. 템플릿 모드는 최신 사실을 조사하지 않습니다.

Blogger 글 편집 화면의 검색 설명에 별도로 붙여 넣으세요.

첨부 예시처럼 카드로 정리하기

카드는 한 줄에 하나씩 입력합니다. 제목과 내용은 | 로 구분하세요. 빈 항목은 표시하지 않습니다. 금액·기간은 출처에서 확인한 내용만 입력하세요.

자주 묻는 질문

공식 참고 자료

AI 작성일을 사실 검증일로 자동 표시하지 않습니다. 직접 확인한 날짜만 입력하세요.

네이버 블로그 · 홈판 준비

홈판은 네이버의 추천 영역이며 직접 등록하거나 노출을 보장할 수 없습니다. 공식 블로그 글쓰기 API는 종료되어 직접 발행이 필요합니다. 아래는 현재 글의 근거를 유지한 네이버용 준비 기능입니다.

네이버 블로그 열기

이미지 문구 제안입니다. 실제 대표 이미지는 사용 권한이 있는 사진 등을 직접 지정하세요.

본문 복사는 광고·스크립트 없는 서식과 텍스트를 제공합니다. 네이버 편집기에 붙여 넣은 뒤 최종 서식과 출처 링크를 확인하세요. 현재 글을 수정했으면 다시 준비하세요.

검색 노출을 위한 기본 점검

본문 소제목·목차·출처·FAQ를 지원합니다. 사이트 색인·canonical·테마 제목 구조는 Blogger에서 관리합니다.

블로그에 등록

예약은 한국 시간입니다. 변경된 내용을 다시 등록하면 새 글이 생깁니다. 기존 글 수정은 Blogger에서 하세요.

설정을 바꾸면서 옆 미리보기로 확인하세요

광고 위치와 코드

본문과 구분한 상단·중간·하단 자리입니다. 광고 로더는 한 번만 포함하세요. 코드가 없으면 실제 발행본에서는 자리를 숨깁니다.

미리보기는 광고 자리를 보여주며 실제 광고나 외부 스크립트는 실행하지 않습니다. 광고 코드는 실제 Blogger 페이지에서 확인하세요.

🔑 API 연결 현황

아래 카드에서 ⚠️ 연결 필요 항목의 발급받기 ↗로 키를 받은 뒤 입력하러 가기를 눌러 붙여 넣고, 맨 아래 저장을 누르세요. 처음 한 번만 하면 됩니다. API 키는 Windows 계정으로 암호화해 실행 파일 옆에 저장합니다. 이 화면으로 다시 전송하지 않습니다.

네이버 검색광고 — 검색량·연관 키워드 필수

네이버 검색광고의 API 관리에서 발급하세요.

최근 월간 PC·모바일 검색량과 검색광고 CTR을 조회합니다. 과거 특정 월의 절대 검색량을 반환하는 기능은 아닙니다.

네이버 데이터랩 — 월별 검색 추이 선택

네이버 데이터랩 API를 등록하세요.

각 키워드의 조회 구간 내 최고=100인 상대 추이입니다. 서로 다른 키워드 간 절대 검색량 비교에는 사용하지 않습니다.

OpenAI — 웹 검색을 포함한 자연스러운 글 작성 필수

OpenAI API 키 발급 · ChatGPT 구독과 별도 API 사용료가 발생합니다.

Responses API·웹 검색·구조화 출력을 지원하는 모델을 입력하세요. 키워드와 참고 메모는 글 작성 시 OpenAI로 전송됩니다.

SNS 게시 연결 선택

직접 발급한 게시 권한이 있는 사용자/페이지 액세스 토큰을 입력하세요. Facebook은 개인 프로필 대신 페이지 게시를 지원합니다. 토큰 만료나 권한 변경 때 갱신해야 합니다. X는 사용자 컨텍스트 쓰기 토큰이며 앱 전용 Bearer 토큰은 사용할 수 없습니다.

개발자 앱 설정·계정 권한·플랫폼 비용은 각 서비스에서 확인하세요. 연결 여부는 키 저장 여부이며 실제 권한은 게시 요청에서 확인됩니다.

텔레그램 알림 권장

① 텔레그램에서 @BotFather에게 /newbot 을 보내 봇을 만들고 토큰을 받습니다. ② 만든 봇과의 대화창에서 /start 를 보냅니다. ③ @userinfobot에게 아무 메시지나 보내면 내 채팅 ID(숫자)를 알려 줍니다. 글이 발행되거나 검토가 필요하거나 오류가 나면 이 채팅으로 알림이 옵니다.

먼저 아래 ‘API 연결 설정 저장’을 누르세요.
키를 입력한 뒤 꼭 이 버튼을 누르세요.

Google Blogger 연결 필수

Google Cloud에서 Blogger API v3를 켜고 데스크톱 앱 유형의 OAuth JSON을 다운로드하세요.

월별 데이터와 애드센스 CTR

CSV 양식에 month, keyword, search_volume, ad_impressions, ad_clicks, source를 입력하세요. 광고 CTR은 클릭 수 ÷ 광고 노출 수로 계산합니다. 월·키워드별 데이터 연결은 직접 지정해야 합니다.

애드센스 원본 CSV 형식을 자동 해석하는 기능은 아닙니다. 글 또는 채널의 광고 지표를 키워드와 정확히 연결해 이 앱의 양식으로 정리하세요. 검색 결과 CTR·페이지 CTR을 광고 노출 CTR과 섞지 마세요.

월별 키워드 → 심층 글 → 자동 게시

이번 달 검색량 TOP 1~50 키워드를 검색량 순서대로 하나씩 쓰고, 50개를 다 쓰면 연관 검색어로 이어서 계속 씁니다. 설정한 간격(예: 1~3시간) 안에서 무작위 시각에 실행됩니다. 이미 쓴 키워드는 다시 쓰지 않습니다. 앱이 실행 중이고 PC가 켜져 있어야 합니다(절전 모드 해제 권장). 최신 조사·작성·사실 대조에 API 사용료가 발생합니다.

미확인 사항·사실 점검 실패·분량 부족은 검토 대기로 남습니다. 자동 사실 점검은 정확성을 보장하지 않습니다. 아래 게시 채널은 Blogger 본문 + SNS 요약·링크입니다.

작성·게시 대기 목록

게시 결과가 불명확한 경우 재전송하지 않습니다. 채널에서 확인한 게시 ID를 기록한 뒤 나머지 채널을 진행하세요.
